This repository contains Jupyter notebooks that teach Machine Learning and Deep Learning concepts using practical examples.

## 🧪 Install Using Conda

### 1. Clone the repository

```bash
git clone https://github.com/ageron/handson-ml2.git
cd handson-ml2
```

### 2. Create the Conda environment

```bash
conda env create -f environment.yml
```

### 3. Activate the environment

```bash
conda activate tf2
```

### 4. Register the Jupyter kernel

```bash
python -m ipykernel install --user --name=python3
```

### 5. Start Jupyter Notebook

```bash
jupyter notebook
```

Then open:

```text
index.ipynb
```

---

## 📦 Install Using pip

Conda is recommended, especially on Windows or when using GPU dependencies.

But if you want to use pip:

```bash
python -m venv .venv
```

### Windows

```bash
.venv\Scripts\activate
```

### macOS / Linux

```bash
source .venv/bin/activate
```

Then install dependencies:

```bash
pip install -r requirements.txt
```

Start Jupyter:

```bash
jupyter notebook
```

## 🧯 Common Installation Issues

### 1. Conda environment creation fails

Try updating Conda:

```bash
conda update -n base -c defaults conda
```

Then recreate the environment:

```bash
conda env remove -n tf2
conda env create -f environment.yml
```

---

### 2. Jupyter kernel does not appear

Run:

```bash
python -m ipykernel install --user --name=python3
```

Then restart Jupyter.

---

### 3. pip install fails on Windows

Some packages may require build tools.

Recommended solution:

```text
Use Conda instead of pip.
```

If you still want pip, install:

- Microsoft C++ Build Tools
- SWIG for some reinforcement learning dependencies
- Compatible Python version

---

### 4. TensorFlow GPU is not detected

Check:

```python
import tensorflow as tf
print(tf.config.list_physical_devices("GPU"))
```

If no GPU appears:

- Check NVIDIA driver
- Check CUDA compatibility
- Check cuDNN compatibility
- Check TensorFlow version
- Try CPU mode first

---

### 5. Notebook output looks different

This may happen because of:

- Different library versions
- Random seeds
- Platform differences
- Dataset download changes
- GPU vs CPU execution

For learning purposes, small output differences are usually fine.

## ❓ FAQ

### Which Python version should I use?

Python 3.8 is recommended for this repository because the environment file is designed around it.

---

### Should I use Conda or pip?

Conda is recommended, especially for Windows users and GPU-related dependencies.

pip can work, but dependency issues are more likely.

---

### Can I run the notebooks without GPU?

Yes. Most notebooks can run on CPU.

Deep Learning notebooks may be slower on CPU.

---

### Why are some results different from the book?

Possible reasons:

- Randomness in training
- Different library versions
- Hardware differences
- Updated datasets
- CPU/GPU differences

---

### Can I use this repository for learning today?

Yes. The core ML concepts are still useful.

However, for latest APIs and newest book content, check the newer edition repositories.

---

### Can I contribute a new notebook?

It is better to open an issue first before adding a new notebook.

For a book-based repository, maintainers usually prefer focused fixes over large new additions.
